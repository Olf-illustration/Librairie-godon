# Librairie Godon — Site vitrine

Site vitrine de la **Librairie Godon**, libraire spécialisée en livres anciens et modernes à Lille (Vieux Lille).

## Structure

```
librairie-godon/
├── index.html        # Page unique (single-page vitrine)
├── css/
│   └── style.css     # Styles (CSS custom properties, responsive)
├── js/
│   └── main.js       # JavaScript vanilla (sans jQuery)
└── README.md
```

## Sections

- **Hero** — Animation à l'encre, bouton replay
- **La Librairie** — Présentation, diaporama, membres SLAM & LILA
- **Nos Catalogues** — *L'Amusement d'un Lillois* (1×/an) & *Le Non Livre* (tous les 2 ans) + formulaire d'inscription
- **Contact** — Téléphone, e-mail, formulaire de contact
- **Newsletter** — Popup d'inscription accessible depuis le header

## Technologies

- HTML5 sémantique
- CSS3 (custom properties, Grid, Flexbox, animations keyframe)
- JavaScript vanilla (Intersection Observer, pas de jQuery)
- Google Fonts : Playfair Display + EB Garamond

## Déploiement

Site statique — compatible **GitHub Pages**, Netlify, Vercel ou tout hébergeur web.

### GitHub Pages

1. Pousser le repo sur GitHub
2. `Settings` → `Pages` → Source : `main` / `/ (root)`
3. Le site est accessible à `https://<username>.github.io/<repo>/`
